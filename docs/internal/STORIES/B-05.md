# B-5 — Panel interno con ficha, etapa y transcripción

**Épica:** E2 · Canal y borde  
**Prioridad:** P0 · **Puntos:** 5 · **Track:** B  
**Depende de:** C-3

## Historia de usuario

Como asesor, quiero ver la lista de mis leads y la ficha completa de cada uno (score, etapa, transcripción), para dar seguimiento sin depender de Telegram directamente.

## Criterios de aceptación

- [ ] Vista de lista filtrada por zona del asesor.
- [ ] Ficha con datos + score + visitas + conversación en orden cronológico.
- [ ] 404 uniforme para token inválido o lead de otra zona — nunca 401/403, para no filtrar información por el código de estado.

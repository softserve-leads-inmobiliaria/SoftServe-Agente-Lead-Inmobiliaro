# Z-4 — Documentación publicada y enlazada

**Épica:** E5 · Cierre y demo  
**Prioridad:** P1 · **Puntos:** 1 · **Track:** Cross  
**Depende de:** Z-3

## Historia de usuario

Como cualquier persona nueva en el proyecto, quiero llegar al índice de documentación desde el README raíz sin tener que saber que existe una carpeta con otro nombre, para no perderme contenido ya escrito.

## Criterios de aceptación

- [ ] `docs/README.md` enlazado desde la primera sección del `README.md` raíz.

## Definition of Done

- [ ] Código en `main` vía PR revisado por al menos otra persona del equipo (idealmente quien consume el contrato/módulo desde el otro lado).
- [ ] Suite de tests del servicio/paquete afectado en verde en CI.
- [ ] Ningún *contract test* roto (`tests/contracts/`).
- [ ] Estado de la historia actualizado en GitHub Issues/Project — nunca en este archivo (ver `docs/ESTRUCTURA-DEL-PROYECTO.md` §5).
- [ ] Si la historia introduce o cambia una decisión de arquitectura, tiene su entrada correspondiente en `docs/DECISIONS/decisions.md`.

## Notas para v2 (aprendido en v1)

En v1 este enlace faltó desde el índice de navegación hasta el cierre del proyecto (DT-48). Con el árbol único `docs/` de v2, este enlace debería quedar puesto desde CT-5 — esta historia (Z-4) solo confirma que sigue vivo al cierre, no lo crea por primera vez.

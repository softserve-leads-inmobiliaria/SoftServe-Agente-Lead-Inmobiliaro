# A-9 — Scoring BANT-E integrado en la FSM

**Épica:** E1 · Motor del agente  
**Prioridad:** P0 · **Puntos:** 2 · **Track:** A  
**Depende de:** C-4

## Historia de usuario

Como asesor, quiero que el score BANT-E se acumule automáticamente turno a turno y se persista, para ver la calificación real de cada lead sin que el LLM la invente.

## Criterios de aceptación

- [ ] Score persistido en Postgres desde este commit (mismo criterio que A-1).
- [ ] El LLM extrae señal cruda por turno; nunca emite el número final.

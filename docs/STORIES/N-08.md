# N-8 — Vista de inventario y negocio en el panel

**Épica:** E6 · Inteligencia comercial  
**Prioridad:** P1 · **Puntos:** 3 · **Track:** B  
**Depende de:** N-2, N-6, N-7

## Historia de usuario

Como gerente, quiero ver en el panel las métricas de inventario, rotación y atribución, para responder estas preguntas sin pedirle una consulta a nadie.

## Criterios de aceptación

- [ ] Página nueva en el panel con las secciones de N-6 y N-7 y un selector de periodo (última semana, último mes o rango).
- [ ] Acceso según N-2; un token que no corresponde responde 404, como el resto del panel.
- [ ] Solo agregados: ninguna sección muestra conversación, teléfono, correo ni nombre del lead. La lista de estancadas muestra propiedades, no leads.
- [ ] Enlace desde el funnel de B-9 y de vuelta.
- [ ] Con la base vacía, cada sección dice "sin datos" en vez de fallar.
- [ ] Tests de las rutas en `services/panel/tests`.

## Definition of Done

- [ ] Código en `main` vía PR revisado por al menos otra persona del equipo (idealmente quien consume el contrato/módulo desde el otro lado).
- [ ] Suite de tests del servicio/paquete afectado en verde en CI.
- [ ] Ningún *contract test* roto (`tests/contracts/`).
- [ ] Estado de la historia actualizado en GitHub Issues/Project — nunca en este archivo (ver `docs/ESTRUCTURA-DEL-PROYECTO.md` §5).
- [ ] Si la historia introduce o cambia una decisión de arquitectura, tiene su entrada correspondiente en `docs/DECISIONS/decisions.md`.
- [ ] Verificada en vivo con la historia sintética de N-9 cargada.

## Notas de diseño

# CT-7 — Fake LLM y fake core

**Épica:** E0 · Contratos y entorno

## Historia de usuario

Como equipo, quiero un fake LLM y un fake core (evento → respuesta fija por intención) para que el resto de servicios se construya sin esperar credenciales reales del proveedor de LLM.

## Criterios de aceptación

- [ ] Respuestas fijas por categoría de intención.
- [ ] Ninguna llamada de red real.
